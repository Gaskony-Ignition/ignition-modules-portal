Ignition modules

Free, open-source modules for Ignition. Pick a version, download the .modl, install it on your gateway.

Ignition 8.3+ · Java 17 · signed builds

Installing

Gateway → Config → Modules → Install or Upgrade a Module, select the .modl, accept the Gaskony certificate.

Published as-is, not actively supported

No support commitment or roadmap. Questions go to Discussions, bugs to the module's issues; a pull request on the module repository is the fastest way to get a fix.
